# E-Commerce Data Analysis Project Documentation

## Project Title

E-Commerce Store Data Analysis Using Microsoft Excel

## Objective

The objective of this project is to analyze an e-commerce dataset using Microsoft Excel. The project involves data cleaning, data transformation, data analysis, visualization, and dashboard creation to generate meaningful business insights from sales, customer, product, and store data.

## Dataset Description

The dataset consists of four tables:

### 1. Customer_Dim

Contains customer-related information such as:

* Customer ID
* Customer Name
* Age
* Gender
* City
* State
* Loyalty Level

### 2. Product_Dim

Contains product-related information such as:

* Product ID
* Product Name
* Category
* Sub-Category
* Brand
* Cost
* Stock

### 3. Store_Dim

Contains store-related information such as:

* Store ID
* Store Name
* Region
* City
* Store Type

### 4. Sales_Fact

Contains transactional sales information such as:

* Sales ID
* Order Date
* Customer ID
* Product ID
* Store ID
* Quantity
* Unit Price
* Discount
* Payment Type
* Total Amount

## Data Cleaning Process

### Handling Missing Values

* Checked all tables for blank values.
* Missing values in Loyalty Level and other categorical fields were replaced using the most frequent value (mode) where appropriate.
* Missing numerical values were reviewed and handled based on business requirements.

### Duplicate Removal

* Checked for duplicate records using Excel's Remove Duplicates feature.
* Verified unique identifiers such as Customer ID, Product ID, Store ID, and Sales ID.

### Data Formatting

* Standardized text formats using Find and Replace.
* Corrected inconsistent naming conventions.
* Verified data types for numerical and categorical columns.

### Data Validation

* Applied validation rules to maintain data accuracy and consistency.
* Checked for invalid entries in Age, Quantity, Discount, and other numerical fields.

## Data Integration Using XLOOKUP

XLOOKUP was used to combine information from multiple tables.

Examples:

* Retrieved Product Name and Category from Product_Dim.
* Retrieved Customer Name and Loyalty Level from Customer_Dim.
* Retrieved Store Name and Region from Store_Dim.

This helped create a unified dataset for analysis and reporting.

## Calculated Fields

### Gross Sales

Gross Sales represent the total sales value before discounts.

Formula:
Gross Sales = Quantity × Unit Price

### Discount Amount

Discount Amount represents the value deducted from Gross Sales.

Formula:
Discount Amount = Gross Sales × Discount

### Net Sales

Net Sales represent the actual revenue after discounts.

Formula:
Net Sales = Gross Sales − Discount Amount

## Descriptive Statistics

Descriptive statistics were generated using Excel's Data Analysis ToolPak.

The following measures were calculated:

* Mean
* Median
* Mode
* Standard Deviation
* Minimum
* Maximum
* Range

These statistics helped understand the distribution and variability of sales data.

Pivot Tables were created to summarize and analyze the dataset.

### Sales by Category

### Sales by Region

Compared sales performance across different regions.

### Payment Method Analysis

Analyzed customer payment preferences using transaction counts.

### Customer Loyalty Analysis

Evaluated revenue contribution by loyalty levels.

* Pivot Tables

* Region

The dashboard enables users to filter and analyze data dynamically.

## Key Insights

* Certain product categories generated higher revenue than others.
* Regional sales performance varied significantly.
* Digital payment methods were preferred by customers.
* Loyal customers contributed a substantial portion of total sales.

## Conclusion

This project demonstrates the application of Microsoft Excel for data cleaning, data transformation, statistical analysis, visualization, and dashboard creation. The analysis provides valuable insights into customer behavior, product performance, sales trends, and business operations, supporting data-driven decision-making.
